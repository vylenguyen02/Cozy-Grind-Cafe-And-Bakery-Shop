# Cozy Grind Cafe & Bakery Shop Database

## 📚 Overview
This project was completed as part of CNIT 27200: Database Fundamentals at Purdue Polytechnic. It involves the design, implementation, population, and testing of a relational database using Oracle SQL.

## 📌 Project Phases

### Phase 1: Database Design
- Designed a normalized relational database (ERD logical and physical models)
- Defined entities, attributes, relationships, and constraints

### Phase 2: DDL and Data Load
- Re-designing the ERD to match all of the requirements
- Forward-engineered DDL from the ERD
- Populated the database using DML (INSERT) statements
- Verified data accuracy with SELECT * queries and DESCRIBE statements

### Final Phase: Testing
- Wrote and executed 30+ SQL queries including joins, subqueries, aggregate functions, and set operations
- Documented the output and tested database integrity
- Reflected on the learning process and evaluated team performance

## 📁 Folder Contents
- `/docs/`: Project instructions, ERDs, and documentation
- `/sql/`: All SQL scripts and outputs
- `/reflections/`: Individual team member reflections
